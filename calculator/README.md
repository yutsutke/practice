# 電卓アプリ

ブラウザだけで動く電卓です。ビルド不要・外部ライブラリなしの HTML 1 ファイル構成なので、
`calculator/index.html` をブラウザで開けばそのまま使えます。

## 使い方

```
# ファイルをダブルクリックするか、ブラウザにドラッグ＆ドロップ
open calculator/index.html          # macOS
xdg-open calculator/index.html      # Linux
start calculator\index.html         # Windows
```

## 機能

| 機能 | 説明 |
| --- | --- |
| 四則演算 | `+` `-` `×` `÷`。掛け算・割り算を先に計算する優先順位に対応 |
| かっこ | `( )` キーが状況に応じて開きかっこ／閉じかっこを自動で判断 |
| パーセント | 後置の `%` は「100 で割る」。例: `200×10%` → `20` |
| 符号反転 | `±` で入力中の数値をプラス／マイナス切り替え |
| 途中結果のプレビュー | 入力しながら現時点の答えを薄字で表示 |
| 履歴 | 直近 20 件を保持。タップすると結果を再利用できる |
| ダーク／ライト | OS の設定に追従。`◐` ボタンで手動切り替え（設定は保存されます） |
| 誤差の丸め | `0.1 + 0.2` は `0.30000000000000004` ではなく `0.3` と表示 |
| 桁区切り | `1,234,567,000` のようにカンマ区切りで表示 |

## キーボード操作

| キー | 動作 |
| --- | --- |
| `0`–`9` `.` `,` | 数値入力 |
| `+` `-` `*` `/` `%` `(` `)` | 演算子・かっこ |
| `Enter` / `=` | 計算 |
| `Backspace` | 1 文字削除 |
| `Esc` / `Delete` / `C` | 全消去（AC） |
| `N` | 符号反転（±） |

## 実装メモ

`eval()` は使わず、字句解析 → 操車場アルゴリズムで逆ポーランド記法に変換 →
スタックで評価する、という手順で自前の計算エンジンを実装しています。

- 単項の `+` / `-`（`5×-3` など）は二項演算子より高い優先度の右結合演算子として処理
- `0` 除算・かっこの不一致・式の途中終わりなどは日本語のエラーメッセージを表示
- 表示は内部表現（ASCII）とは分離し、`*` → `×`、`/` → `÷`、`-` → `−` に整形して描画
- 結果は 12 桁の有効数字に丸めて浮動小数点誤差を吸収し、極端に大きい／小さい値は指数表記に切り替え
